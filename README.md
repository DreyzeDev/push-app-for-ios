# PUSH

### Считай отжимания по-настоящему — камера видит твоё тело

Минималистичное чёрно-белое iOS-приложение, которое считает отжимания
по **реальной глубине движения**: камера отслеживает руки, торс, ноги и
лицо через Apple Vision и засчитывает повтор, только когда глубина
опускания достигает **80%**.

`SwiftUI` · `Vision` · `AVFoundation` · `iOS 17+`

## Что внутри

Главное меню — три раздела:

| 🏋️ Режимы | 🏆 Лидеры | 👤 Профиль |
|:--|:--|:--|
| Тренировка отжиманий с трекингом тела камерой | Кто отжался больше всех, вкладки «Все» и «Активные» | Регистрация по почте, аватар, статистика, кастомизация |

## Как работает подсчёт

1. **Режимы → Отжимания → Начать.**
2. Задаёшь **сколько отжиманий в подходе** и **сколько подходов**.
3. Приложение запрашивает доступ к **камере**.
4. Принимаешь упор лёжа — на экране появляется **скелет** (руки, торс, ноги, голова).
5. Сбоку — **шкала глубины 0–100%** с отметкой порога **80%**.
6. Отжимание засчитывается, когда:
   - глубина опускания **≥ 80%** (тело реально ушло вниз), а затем
   - ты **вернулся вверх**.
7. После завершения подхода — **отдых 30 секунд** с таймером, потом следующий подход.
8. Когда все подходы сделаны — итог сохраняется в профиль и в таблицу лидеров.

### Почему именно угол в локте

Глубина считается из **угла в локте** (плечо → локоть → запястье):

```
руки выпрямлены  ≈ 160°   →   0%
нижняя точка     ≈ 85°    →   100%
```

Угол **не зависит от поворота телефона и зеркалирования** камеры, поэтому
счёт остаётся стабильным, даже если оверлей-скелет нарисован чуть со
смещением. Значение сглаживается, чтобы дрожание не накручивало повторы
(`PushupCounter`).

## Дизайн

- Чистый **чёрно-белый** стиль, всегда тёмная тема.
- Крупная типографика (`SF Rounded`), тонкие серые границы.
- Процедурные **аватары в «ИИ»-стиле**: рисуются детерминированно по seed
  (кольца / сетка-identicon / полосы / монограмма). Можно перегенерировать
  или не выбирать вовсе.

## Сборка и запуск

> Нужен **Mac с Xcode 16+** (синхронизированные группы проекта) и iPhone с **iOS 17+**.
> Симулятор камеру не даёт — Vision-трекинг тестируется **только на реальном устройстве**.

```bash
git clone https://github.com/faridhuse40-star/push-app-for-ios.git
cd push-app-for-ios
open PushApp.xcodeproj
```

В Xcode: выбери свою команду подписи (Signing & Team) → запусти на iPhone.
`Info.plist` генерируется автоматически, разрешение на камеру уже прописано.

### Сборка IPA

`Product → Archive → Distribute App`. Для установки без App Store используется
вариант **Ad Hoc / Development** или сторонняя подпись.

## Подключение своего сервера (потом)

Сейчас всё работает **локально** (`AppConfig.useMockBackend = true`):
коды подтверждения генерируются на устройстве и показываются в приложении,
лидерборд — на демо-данных. Никакого сервера не требуется, чтобы собрать и
потестировать приложение.

Когда поднимем API на твоём домене — меняем две строки в
[`AppConfig.swift`](PushApp/App/AppConfig.swift):

```swift
static let useMockBackend = false
static let apiBaseURL = URL(string: "https://api.твой-домен.ру")!
```

`RemoteAPIService` уже реализован и ждёт такие эндпоинты (REST/JSON):

| Метод | Путь | Тело | Ответ |
|:--|:--|:--|:--|
| `POST` | `/auth/request-code` | `{ email }` | `200` |
| `POST` | `/auth/verify-code`  | `{ email, code }` | `200` |
| `POST` | `/auth/register`     | `{ email, nickname, password, avatar }` | `{ user }` |
| `POST` | `/auth/login`        | `{ email, password }` | `{ user }` |
| `GET`  | `/leaderboard`       | — | `{ entries: [...] }` |
| `POST` | `/workouts`          | `{ result, userId }` | `{ user }` |

Реальную отправку кода на почту делает сервер; приложение только показывает
поле для ввода кода.

## Заметки по приватности

- Видео с камеры **обрабатывается только на устройстве** (Apple Vision), никуда не отправляется.
- В демо-режиме пароли хранятся локально в открытом виде — **только для теста**.
  На реальном сервере пароль в приложении не хранится.
